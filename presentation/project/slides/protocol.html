How we kept the evaluation honest

RuleWhat it means here
MUCH’s own splitTest = its 200 human-annotated answers (867 claims); train = the other 4,673
Train-only choicesEvery setting picked by cross-validation on train, frozen to a file before test was read
Fair criterionRanked by mean per-model score, so knowing which model wrote a claim can’t inflate it
Baseline reproducedCCP 0.775 here vs 0.772 published
Uncertainty shown95% bootstrap confidence intervals; differences paired on identical claims
An early version of this project reported wins that an audit showed were invalid: no train/test split and choices made on test data. Everything shown from here on follows these rules. The MUCH test split was read twice in total, once by an earlier version and once by the final one, and we say so.
