From tokens to a claim score

1. One pass

Replay the answer; read G, S, D from 4 heads per layer

2. Per claim

Mean, max, min over content words, in 8 depth bins

3. Add free signals

Token probabilities the model already produced + claim length

4. Small classifier

Gradient-boosted trees → hallucination probability

393 features per claim. No sampling, no NLI model, no change to the LLM. The classifier is trained on labelled claims: this is a supervised detector.

Depth bins let models with different numbers of layers share one feature space. The token probabilities come from the same forward pass, so they are free. The final classifier is small and runs on a CPU in under a millisecond per claim.
